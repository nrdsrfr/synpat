Connecting uses the MIDI In/Out chosen here and asks the browser for SysEx permission. Close Elektron Transfer first: it holds the MIDI port.

Audition sends a Program Change, which selects the pattern in the project currently loaded on the device (not the file shown here). On the Syntakt enable SETTINGS → MIDI CONFIG → PORT CONFIG → "PRG CH RECEIVE" and set its channel (AUTO CHANNEL) to match.

Connecting, listing and "Back up" only read from the device ("Back up" saves a new .stprj in the output folder). Writing to the device ("Load…", or "Write to Syntakt" when running a queue) only ever targets EMPTY slots, only after you confirm, and is verified by read-back; existing projects are never overwritten.
